# AiriLife v2 TTS 推理服务 —— GSV-TTS-Lite（纯 PyTorch GPU 推理）
#
# 引擎：gsv-tts-lite 0.4.7。基于 GPT-SoVITS V2ProPlus 的 torch 推理，
# 质量与官方 torch 一致（取代 genie-tts ONNX 方案）。token 级流式，RTX4070 实测首块 ~120ms。

# 安装：
#   1) Python 3.11 环境：
#        conda create -n gsv python=3.11 -y

#        pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
#   3) 再装本文件：
#        pip install -r requirements.txt
#
# 首次运行 tools/tts_server.py 会自动下载预训练模型（cnhubert/roberta/g2p/sv，~1.3GB）到 gsv_models/
